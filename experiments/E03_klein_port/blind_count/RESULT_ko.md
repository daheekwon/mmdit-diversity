# E03 ho3 — 눈으로 센 실패와 실패를 뺀 Vendi (2026-11-06, 사후 분석)

기준: CRITERIA_ko.md. 대상: ho3 18 prompt × seed 16 = 조건마다 288장. 한 사람(Claude)이 셌다.
1단계: 조건을 가린 192 px 시트로 셈 (counts.csv, 10:38 고정).
2단계: 조건을 연 뒤, 판정기만 깨졌다고 본 이미지를 원본 크기로 다시 봄 (judge_only_verified.csv, 조건을 알고 함).
최종 실패 = 1단계 ∪ 2단계에서 실패로 확인된 것. 스크립트: make_blind.py, analyze.py (`--final`), 결과 result_final.json.

## 읽기
- λ1.7: 실패를 빼도 DAVE보다 다양하다. 하지만 실패는 DAVE보다 적지 않다(69 대 58, 차이는 유의하지 않음). 그래서 "λ1.7이 DAVE보다
  낫다"의 두 조건 중 실패 수 조건을 못 넘는다. 실패 종류가 다르다: 우리는 구조 실패가 DAVE의 2배 이상, DAVE는 화풍 실패가 많다.
- λ1.5: 실패를 뺀 다양성은 DAVE와 같은 수준이고, 실패는 적다(구간이 0을 살짝 넘음).
- λ1.3: 다양성은 DAVE와 같은 수준(구간이 0을 포함)이고, 실패는 유의하게 적다. 원래 Vendi로는 규칙 1을 못 넘었다(−0.25).
- 판정기는 우리 방법의 구조 실패(칸 나뉨, 띠, 테두리)를 거의 못 잡는다. DAVE의 화풍 실패는 대부분 잡는다.
- 한계: 한 사람이 셌다. Original 행은 깨끗해서 가려도 알아볼 수 있었다. 2단계는 조건을 알고 했다. 작은 글자, 앨범 표지,
  애매한 띠는 1단계에서 세지 않았다. 사전 규칙 2(MUSIQ 포함)를 대신하는 사후 기준이다.
