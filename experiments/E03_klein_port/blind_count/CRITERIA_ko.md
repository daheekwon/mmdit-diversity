# E03 ho3 눈으로 센 실패 — 기준 (보기 전에 작성, 2026-11-06 10:3x; 셈은 10:38에 counts.csv로 고정, counts.md5)

대상: ho3 18 prompt × seed 16, 조건 5개 — Original, DAVE α0.2 블록 13 스텝 0–10, 우리 방법 λ1.3·1.5·1.7 (블록 0–24, V·pad V ¼ 스텝 0–10).
방법: prompt마다 조건 순서를 무작위로 섞어 A–E 행으로 놓은 시트(seed 0–7, 8–15 두 장)를 보고 센다. 어느 행이 어느 조건인지는
key.json에만 있고, 셈을 counts.csv에 다 적은 뒤에 연다.

실패 종류 (한 이미지에 여러 개면 가장 앞의 것 하나):
- panel: 화면이 둘 이상의 칸/액자/콜라주로 나뉨
- bar: 위·아래·옆의 띠(레터박스), 화면을 가로지르는 흰 선이나 검은 선, 부자연스러운 테두리
- insert: prompt에 없는 사람·얼굴·큰 물체가 주요 피사체처럼 끼어듦 (사람이 나오는 prompt의 사람은 제외)
- noise: 알아볼 수 있는 장면이나 피사체가 없음 (노이즈, 추상 질감)
- deform: 피사체가 심하게 일그러짐 (덩어리, 팔다리·부리 등 기형)
- style: 사진이 만화·평면 그래픽·조각·판화로 바뀌거나 큰 글자/배너가 화면을 덮음

실패가 아님: 어둡거나 가까이 찍은 사진(피사체를 알아볼 수 있으면, [dark-fail-metric] 규칙), 흑백·세피아 사진, 배경·구도 변화.
주제가 바뀐 것(불일치)은 판정기가 따로 재므로 여기서는 세지 않는다.
구조 실패 = panel + bar + insert + noise + deform. 전체 실패 = 구조 실패 + style.

실패를 뺀 Vendi: prompt마다 다섯 조건에서 실패가 아닌 이미지 수의 최솟값 k로 맞추고, 실패가 아닌 이미지에서 k개를 무작위로
뽑는 일을 500번 반복해 평균 Vendi(DINO)를 낸다. 같은 k로 실패를 빼지 않은 Vendi도 같이 낸다(이미지 수 효과와 실패 효과를 나누려고).
k < 6인 prompt는 빼고 몇 개 뺐는지 적는다. 신뢰구간은 prompt bootstrap 2000번.
