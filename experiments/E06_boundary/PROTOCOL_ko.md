## 4. 지표

**다양성.**

- 주지표: Vendi(DINO). `value_diversity/vendi_eval.py`, prompt마다 8 seed(ho4는 16 seed).
- 정상 이미지 Vendi: 망가짐도 불일치도 아닌 이미지만 쓴다(판독 CSV의 broken = 0과 같다). 비교하는 조건들 사이에서 prompt마다 같은 장수 k(그 prompt에서 조건별 정상 장수의 최솟값)를 seed 번호 순으로 뽑는다. k < 3인 prompt는 뺀다.
- 보조: 구도 다양성(8×8 색 배치), 색 다양성, Vendi(CLIP).

**비용.**

- 판독기(Qwen3-VL-8B, `study_judge.py`): 망가짐 비율(defect ≥ .5 또는 style ≥ .5), 불일치 비율(match < .5), style 비율. 망가짐은 이전 generalize 분석과 같은 정의다(§11 수정: 처음 판은 판독 CSV의 broken 열, 즉 불일치까지 포함한 값을 썼다).
- 망가짐을 defect와 style로 나눠서도 보고한다(§12). SD3.5에서는 style 판정에 흑백 평면 그래픽(엄격 실패)이 섞이므로, `dark_fail.py`의 판독 질문 'graphic'(흑백 평면 그래픽, 사후 검정 균형 정확도 0.92)을 따로 돌려 화풍 이동과 품질 붕괴를 가른다.
- MUSIQ(`study_eval.py`).
- VQA(Qwen3-VL-8B 예/아니오): 희귀 개념은 존재 질문 1개, 어려운 구성은 `common.CHECKS`의 질문(관계·개수 포함). COCO 캡션은 VQA를 하지 않는다(판독기 불일치로 본다).
- 물체 크기: CLIPSeg 마스크 면적 비율(`common.OBJECTS`, 희귀 개념은 그 단어). 물체 log-면적의 조건 평균 이동과 seed 간 분산을 함께 본다.

**기술용 (비용 아님).**

- 어두운 비율: `dark_fail.dark_share > 0.3`(밝기 25 미만 픽셀이 30% 넘는 이미지). 11-03 결정대로 비용과 판정에 넣지 않는다.
- 어두운 이미지 안의 판독 불일치율(원본·DAVE 대비), 조명 명시 prompt(comp_06, comp_07)의 어두운 비율.

**통계.** prompt 단위 짝 bootstrap 95% 구간(prompt 재표집 2,000회). 원본과 같은 prompt·seed로 짝짓는다.

## 5. 판정 규칙

**안전 창.** 원본 대비 다음을 모두 만족하는 용량 구간이다(11-05 확정).

- ΔVendi > 0 (구간 하한 > 0)
- 망가짐 − 원본 ≤ +2pp, 불일치 − 원본 ≤ +2pp (점추정, 기존 DAVE 비교 규칙과 같은 방식)
- MUSIQ − 원본 < −1(점추정)이면 **플래그**다(§10 수정, 처음 판은 경성 기준). 플래그가 선 조건은 시트 규칙으로 판정한다: 엄격 실패율 − 원본 ≤ +2pp면 창 안이다.
- 새 prompt 전체와 희귀 개념 묶음 모두에서 성립해야 한다. 두 모델에서 따로 판정한다.

**시트 규칙 (§10).**

- 표본: 그 조건과 원본에서 같은 prompt 25개(고정 섞기, seed 0) × 8 seed = 각 200장. 조건을 가린 시트로 assistant가 라벨을 붙이고, 애매하면 실패가 아닌 것으로 둔다(11-03 엄격 실패 라벨과 같은 방식).
- 엄격 실패: 알아볼 수 없는 실루엣·클로즈업, 흑백 평면 그래픽, 붕괴(noise 무늬 포함), prompt가 명시한 물체가 잘려 알아볼 수 없거나 빠짐.
- 실패가 아닌 것: 확대·클로즈업 자체(구도 변화), 어둡지만 알아볼 수 있는 이미지(11-03 결정).

**보고 단위: 창이 끝나는 ΔVendi (§12).** 마진은 그대로 두고, 조작마다 망가짐 또는 불일치 − 원본이 +2pp를 넘는 지점의 ΔVendi를 보고한다. 이웃한 두 용량 점 사이를 선형 보간하고, 구간은 prompt bootstrap으로 낸다. 범위 안에서 넘지 않으면 "범위 끝까지 창 안", 첫 편집 점부터 넘으면 "첫 점보다 아래"로 적는다. 곡선이 직선이면 이 값은 2/기울기와 같다. DAVE·CADS는 한 점뿐이라 원점을 지나는 직선을 가정한 2/(비용/ΔVendi)를 참고값으로만 쓴다. 비용이 0에 가까우면(예: FLUX COCO48 DAVE +0.4) 이 참고값은 불안정하므로 기울기와 구간을 같이 적는다. 창이 defect에서 끝나는지 style에서 끝나는지도 같이 적는다.

실제 방법(조합)의 창 끝은 pad ¼를 고정한 조합 경로에서 잰다(§13). 경로의 점은 원본(0), pad ¼만(E2의 padv0.25), 아래 점(SD3.5 λ1.07, FLUX λ1.43), 최종점이다.

**비용 기울기.** 각 조작(E1, E2)의 용량 곡선에서, 망가짐과 불일치의 원본 대비 증가를 ΔVendi에 대해 원점을 지나는 직선으로 맞춘다. 기울기 = Vendi 1당 비용 증가(pp). bootstrap으로 구간을 낸다.

**무릎 판정 (§10 수정).** prompt 단위 점(prompt × 용량 조건, x = 원본 대비 ΔVendi, y = 원본 대비 망가짐 증가 pp)으로 맞춘다. 불일치도 같은 방식으로 따로 판정한다.

- 직선: 원점을 지나는 기울기 하나(모수 1).
- 꺾은선: 원점을 지나고, 곡선 안쪽 용량 점 중 하나의 평균 ΔVendi에서 꺾이는 연속 두 직선(모수 3: 두 기울기와 꺾는 점).
- AIC = n·ln(SSE/n) + 2k. n은 prompt × 조건 점의 수(약 300)라 AICc 보정(2k(k+1)/(n−k−1) < 0.1)은 무시한다. 같은 prompt의 점들은 서로 독립이 아니므로, 판정은 아래 두 조건을 모두 요구한다(기울기 비의 구간은 prompt 단위 bootstrap).

다음을 모두 만족하면 "무릎 있음"이다.

- AIC_직선 − AIC_꺾은선 > 2
- 뒤 기울기 / 앞 기울기 ≥ 2, 그 비의 prompt bootstrap 구간 하한 > 1

처음 판의 첫 조건("꺾은선의 잔차 제곱합이 직선보다 작은 bootstrap 비율 ≥ 95%")은 꺾은선이 직선을 포함하는 모형이라 항상 참이어서 바꿨다.

그 밖에는 "무릎 없음, 기울기로 보고"다.

**E3 판정 (2단계).** 같은 Vendi에서의 비용 기울기 변화로 판정한다. 차단 조건의 기울기 − 편집만의 기울기의 구간이 0보다 작으면 "깨짐 줄어듦"이다. 다양성은 같은 λ에서 ΔVendi 차이로 본다.

- 네 분기: 깨짐만 줄어듦 / 다양성도 줄어듦(ΔVendi가 편집만의 50% 미만) / 그대로 / 일부.
- "그대로"는 E1의 step 0 신호로 가른다. step 0의 I→T 변화가 깨짐과 같이 움직이면(이미지 단위 순위 상관의 구간 하한 > 0) H1 기각 쪽이다. step 0 신호는 작고 이후 step에서만 커지면 "step 사이 되먹임이라 E3가 못 잡음"이다.

- 보충 규칙(§10): 차단 조건의 ΔVendi(전체 이미지)가 E1의 가장 낮은 편집 점(SD3.5 λ1.07, FLUX λ1.43)의 ΔVendi보다 낮으면, 그 차단 조건에 λ 한 점을 더한다(SD3.5 λ1.3, FLUX λ2.3: E3 두 점 바로 위의 E1 격자 점. pad 차단 조건은 한 단계 강한 s).

**E5 비교.** 우리 조건들과 DAVE·CADS 표준 설정을 원본 대비 같은 표에 나란히 둔다. 우리 강도를 DAVE의 Vendi에 맞추지 않는다. 같은 Vendi 보간은 우리 변형끼리만 쓴다.

- ho4 조합 최종점(§10, 방법의 held-out 확인): ΔVendi ≥ DAVE, 망가짐·불일치 − DAVE ≤ +2pp(점추정). MUSIQ − DAVE < −1이면 플래그이고, 시트 규칙을 DAVE 대비로 적용한다.

**무작위 방향 (E1).**

- 기저: 블록마다 Q(k=256)와 같은 크기의 가우시안 열을 Q의 직교 여공간으로 사영하고 QR로 정규직교화한다(seed 1000+블록). 확인: |QᵀR| 최대 3e-16, RᵀR−I 최대 6e-15. 파일: `outputs/e06_boundary/bases/<model>_random_k256.pt`.

W_out은 SD3.5·FLUX double 블록이 `to_out[0]`, FLUX single 블록이 `proj_out`의 attention 부분이다. 두 모델 모두 CFG 행을 합친 제곱합을 쓴다. λ_r − 1 = (λ_final − 1) × √(ΣE_Q / ΣE_R).
- 결과: SD3.5 E_Q/E_R의 제곱근 = 1.631, **λ_r = 1.228**(조건 이름 `rnd_l1.228`, 실제 적용 λ). FLUX는 큐에서 측정한다(`W_flux`).

**내부 신호 (seed 71000, 71001).** step: SD3.5 0, 1, 11, 12 / FLUX 0, 1, 5, 6. 전 블록. 조건부 행만.

- I→T: 이미지 쿼리의 개념 열 확률(head 평균, 32×32 토큰을 2×2로 묶은 256칸) → JS 거리, 칸별 최대 개념 토큰 뒤집힘 비율, 개념 질량 변화를 원본과 비교한다.
- 개념 K: 개념 토큰의 key(head 연결, RMSNorm 뒤)를 고정 가우시안 128차원으로 사영한다(seed 0). 원본 대비 코사인.
- 블록 입력: 이미지 토큰의 채널 표준편차(LayerNorm σ) 평균과 L2 노름 평균.
- d: 편집 블록에서 편집 전 좌표 c = Qᵀ(V − b)의 토큰 평균과 토큰 RMS. 편집 조건의 좌표는 λc다.
- x̂₀ = x_t − σ·v(SD3.5는 CFG 결합 뒤 v). step 0, 1, 2, 3, 5, 8, 11, 12, 15, 20, 27.

**E3 짝 forward.**

- transformer pre-hook 안에서, 편집 step마다 같은 입력으로 편집 없는 forward를 한 번 더 돈다. step 카운터와 편집 기록에는 한 번만 잡힌다.
- I→T 개념 열 고정은 보정항으로 넣는다: 출력 = 고정 안 한 run의 attention 출력 + (P_고정 − P)V. P_고정은 개념 열을 짝의 확률로 두고 나머지 열을 행 합이 1이 되게 비례 조정한 것이다. 조건부 행에만 건다.

## 22. 사후 분석: I→T 변화를 "어디"와 "무엇"으로 나누기 (2026-11-06, 사용자 "나눠 보기", 계산 전에 씀)

**질문.** 외부 코멘트(11-06)의 예측을 시험한다. "다양성은 공간 재분배(어디)를 따라가고, 비용은 개념 뒤집힘(무엇)을 따라간다." 사전 등록에는 없던 분석이다. 이미 기록한 신호(`probe_sig`, prompt 50 × seed 71000·71001)만 쓰고, 새 생성은 없다.

**두 성분.** 이미지 쿼리의 개념 토큰 확률 맵 P(2×2 묶은 패치 256 × 개념 토큰, head 평균)를 원본 P0(같은 prompt·seed)와 비교한다.
- 공간 재분배(어디): 개념 토큰마다 패치 위 분포 c_k = P[:, k] / Σ_n P[n, k]를 만든다. JS(c_k, c0_k)(밑 2)를 원본 열 질량 비중으로 가중 평균한다.
- 개념 뒤집힘(무엇): 가장 많이 읽는 개념 토큰이 바뀐 패치의 비율이다(`signals.py`의 it_flip과 같다). 연속값으로 패치별 개념 분포 JS(it_js)도 같이 적는다.
- 블록 평균을 쓴다. 주 step은 마지막 편집 step(SD3.5 11, FLUX 5)이고, step 0도 같이 적는다. prompt·조건마다 seed 2개를 평균한다.

**결과 변수 (원본 대비, prompt마다).** ΔVendi, 구도 다양성, 색 다양성, 판독 불일치(%). 실제 실패(§21)는 사건이 너무 적어 쓰지 않는다.

**시험.**
- E1 이미지 V 7점(prompt × 조건 = 350)을 쓴다. 조건마다 prompt 사이에서 z-점수로 바꿔 λ 효과를 뺀 뒤 모아서 회귀한다: 결과_z ~ 어디_z + 무엇_z.
- prompt bootstrap(2,000, prompt를 통째로 재표집)으로 두 계수와 그 차이의 95% 구간을 낸다. 어디와 무엇의 상관도 적는다.
