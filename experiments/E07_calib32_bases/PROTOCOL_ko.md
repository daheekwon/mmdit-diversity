# E07 — 이 서버에서 V편집 기저 새로 적합 (2026-11-06)

요청: 사용자 2026-11-06 ("V편집을 위한 bases/.pt 정본은 여기에서 새로 구할거야").
결정 (사용자, 같은 날): 해상도는 각 모델의 설정 기본값, 보정 prompt는 split과 겹치지 않는 별도 세트, 모델은 SD3.5·FLUX.1·klein.

## 1. 왜 다시 적합하나

이전 기저(`bases/*_legacy_dev8*`, `bases/klein_dev8*`)의 `.pt`는 이 서버에 없다. json 보고서만 git에 있다.
이전 기저는 `value_diversity/`의 dev 일반 prompt 8개 × seed 40000–40015로, SD3.5·FLUX는 512에서 적합했다.

## 2. 설정

| | SD3.5 | FLUX.1-dev | FLUX.2-klein |
|---|---|---|---|
| 해상도 | 1024 (설정 기본값) | 1024 (설정 기본값) | 512 (설정 기본값) |
| block | 전 block 0–23 | 전 block 0–56 | 전 block 0–24 |
| step 세트 | 0–11 (운영점), 0–3 | 0–5 (운영점) | 0–4, 0–6, 0–10 (E03과 같음) |
| 파일 | `sd35_calib32_s0-11_k256.pt`, `sd35_calib32_s0-3_k256.pt` | `flux_calib32_s0-5_k256.pt` (단일 step 세트라 `fit_basis.py`가 `flux_calib32.pt`로 저장, 이름만 바꿈) | `klein_calib32_s0-4/0-6/0-10_k256.pt` |

- 보정 prompt: `splits/calib32.txt` (32개, 8개 범주 × 4개: 동물, 사물, 장면, 사람, 음식, 탈것, 건축, 식물). dev·ho3와 겹치지 않는다(`tests/test_klein.py`).
- seed: `data.calibration` (9000000–9000015, 16개). prompt 하나를 seed 16개 배치로 한 번 돌린다.
- k 256, β 1. 나머지는 `div/basis.py` 그대로이다. 모델마다 캡처는 한 번이고, step 세트마다 기저가 하나씩 나온다.
- 명령: `run.sh`. 로그: `logs/` (git 제외).
- 주의: `.pt`에는 해상도가 기록되지 않는다. 해상도는 이 문서와 `run.sh`의 설정(모델 설정 기본값)으로만 알 수 있다.

## 3. 이전 운영점과의 관계

- 설정의 λ(SD3.5 1.14, FLUX 1.72)는 이전 기저와 512에서 골랐다. 기저와 해상도가 모두 바뀌었으므로, 같은 λ가 같은 세기의 편집이라는 보장은 없다.
- 기저마다 `unit`(λ−1 한 단위당 image V 상대 변화)이 있다. 이전 기저의 unit과 비교한 값은 4절에 적는다.
